# 企业级智能客服作品集

本项目是一个面向合作医生和诊所助理的企业级智能客服模拟项目，同时用于展示 AI 产品经理与初级 Forward Deployed Engineer（FDE）能力。

## 真实性声明

- 本仓库中的用户、机构、病例、工单、知识库和运行数据均为模拟数据。
- 文档中的业务规模与人工基线均为作品集假设，不代表时代天使或任何真实公司的经营数据。
- 指标分为 `baseline_assumption`（模拟现状）、`target`（目标值）和 `measured`（通过本项目测试得到的实测值）。未生成评测报告前，不得将目标值描述为达成结果。
- Dify Workflow 是脱敏后的作品集原型，不代表任何公司的真实生产架构。

## 项目目标

构建一套可运行、可部署、可评测、可解释、可面试展示的智能客服系统，覆盖：

- AI 产品经理：用户研究、问题定义、场景优先级、产品需求、指标、风险和迭代决策。
- 初级 FDE：技术发现、架构、API、权限、数据、部署、测试、监控和客户交付。

## 当前阶段

阶段 5：端到端 Eval 与 Bad Case 修复已完成。Mock Backend 已部署到 Render 公网 HTTPS；Dify 修复版已发布到公开 WebApp。

当前可复现证据：

- Backend 自动化测试：19/19。
- 权限决策：8/8，越权访问成功数为 0。
- 确定性会话记忆契约：15/15；归一化器回归：17/17。
- Dify 浏览器冒烟：主链路 4/4；云端记忆专项另有逐项证据。
- Dify 端到端综合 Eval：150/150，通过率 100%；P50 5.58 秒、P95 8.26 秒，execution error 为 0，release blocker 为 0。
- 综合结果由首轮 API 证据、余额恢复后的 25 条 WebApp 复测，以及修复发布后的 5 条专项回归合并得到；最新证据覆盖同一用例的旧结果。

## 核心原则

1. 高风险场景优先保证安全和正确转人工，不以自动化率为唯一目标。
2. 病例状态只能通过经过鉴权的结构化接口查询，不能从知识库生成。
3. 所有关键回答必须能追溯到知识版本、工具结果或人工处理记录。
4. 每项指标必须有口径、数据来源、计算方式和可复现报告。
5. Demo 的功能、文档中的说法和面试表达必须保持一致。
