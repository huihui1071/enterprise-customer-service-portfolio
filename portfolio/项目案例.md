# 企业级智能客服项目一页总览

> 面向合作医生和诊所助理的模拟企业级智能客服，同时展示 AI 产品经理与初级 FDE 的端到端能力。

**在线 Demo：** [时代天使智能客服 WebApp](https://udify.app/chat/OE5ppsNWR8Zs1AZ5)

**代码与证据：** 私有 GitHub 仓库；Backend 部署于 Render 公网 HTTPS。

**真实性声明：** 用户、机构、病例、工单、知识及业务规模均为模拟数据，不代表任何真实公司的经营数据。

## 问题与产品判断

模拟业务每天有 2,200 次有效咨询。知识问答重复、病例进度查询高频，临床异常则紧急且容错成本高。项目没有把“自动化率最高”作为唯一目标，而是根据结构化程度、确定性和风险决定自动化边界。

| 场景 | 产品决策 | 原因 | 核心指标 |
|---|---|---|---|
| 病例状态查询 | AI 多轮补参后调用鉴权 API 自动完成 | 高频、结构化、数据可确定获得 | 参数补全率、权限校验准确率、端到端准确率 |
| 临床异常 | AI 识别风险、收集证据、立即转人工 | 风险高、误答代价高，AI 不承担诊断 | 高风险召回率、建单成功率、应转未转率 |
| 产品/流程/系统知识 | RAG 检索后生成有边界回答 | 可标准化，但答案必须受知识版本约束 | 回答正确率、引用正确率 |

## 方案与主链路

```text
用户输入
  -> 归一化、实体识别和会话记忆
  -> 高风险硬分流（优先级最高）
  -> 工单查询 / 病例状态查询（确定性 API）
  -> 知识意图分类与 RAG
  -> 拒绝猜测的兜底澄清

Dify Chatflow -> Render HTTPS -> FastAPI -> SQLite Mock Data
```

关键约束：同一轮只输出一个主结果；病例状态不能由 LLM 或知识库推测；账号、任职、助理授权和病例归属必须同时通过；接口失败时明确降级；建单通过 `Idempotency-Key` 去重。

## 我的工作

**AI 产品经理线：** 定义医生与助理 JTBD；对六类场景按频次、价值、结构化程度、风险与成本排序；完成 PRD、业务流程、状态机、指标树、发布门槛及 150 条 Eval；用 Bad Case 驱动迭代，而不是凭主观调 Prompt。

**FDE 线：** 设计 User、Organization、Membership、Assignment、Case、Ticket 和事件模型；使用 FastAPI、SQLite、JWT 构建 Mock Backend；实现对象级鉴权、统一安全提示、幂等建单、故障注入、结构化错误和 trace_id；部署到 Render，并接入 Dify 构建可公开运行的端到端原型。

## 实测结果

| 证据 | measured 结果 |
|---|---:|
| Dify 综合端到端 Eval | **150/150（100%）** |
| 八类切片 | 知识 30/30；意图边界 20/20；病例权限 20/20；高风险 20/20；工单 15/15；知识质量 15/15；多轮 15/15；安全 15/15 |
| 执行错误 / 发布阻断项 | **0 / 0** |
| 端到端延迟 | P50 **5.58 秒**；P95 **8.26 秒** |
| Backend 权限决策 | **8/8**；越权访问成功数 **0** |
| 会话记忆契约 / 归一化器 | **15/15 / 17/17** |
| 幂等建单 / 高风险立即分派 | 通过 / 通过 |

综合 Eval 合并首轮 API 证据、余额恢复后的 25 条 WebApp 复测和修复发布后的 5 条专项回归；最新响应覆盖同一用例旧结果。它证明固定模拟集上的行为，不等于真实生产准确率。

## 三个关键迭代

1. **病例号存在却进入知识库：** 将显式病例号设为确定性查询信号，病例权限切片从 18/20 提升至 20/20。
2. **“保证所有病例明天生产”触发病例号追问：** 从宽泛关键词改为上下文模式，并增加承诺类排除规则。
3. **用户要求系统直接猜测：** 重写兜底 Prompt，明确拒绝猜测、编造和无依据承诺，只在用户确实查询病例或工单时索要编号。

## 边界与生产化路径

- 当前是合成数据作品集，没有真实患者数据、真实 CRM/OMS 或生产 SLA。
- 下一步生产化应接入企业身份源和真实业务 API，使用托管数据库与密钥管理，补齐知识 metadata、审计日志、监控告警、人工质检和灰度发布。
- `150/150` 不应被表述为“模型已达到生产 100% 准确率”；更准确的说法是“当前发布版本通过固定合成回归集，且无发布阻断项”。
